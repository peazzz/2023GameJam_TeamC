# YouShallNotPass
此為2023年數位遊戲海外研習實習計劃之GameJam作品。
## 專案說明
* 遊戲引擎：Unity 2021.3.9
* 支援平台：Windows
## 遊戲玩法
透過點擊空白鍵，形成相對應顏色的盾牌阻止敵人攻擊。
